# dynmdl

## Overview

Package `dynmdl` is an R implementation of Dynare. It can compute the steady steady, compute 
the eigenvalues of the model and perform deterministic simulations.

The R-package files are located in subdirectory **`pkg`** in the project root

## Generated source files

Directory `pkg/src` contains a few  files that are generated by the **Makefile** in 
the project root directory. These files should not be edited manually. But these files
are committed in the Git Repository. 

The generated files are:

  * `makedeps` (both in `pkg/src` and `pkg/src/macro`): these files specify the dependencies of the object files on header files. The file 
     is generated with command `make makedeps` (which calls R script `tools/create_makedep_files`).
  * `DynareFlex.cc` and `macro/MacroFlex.cc` are created with **Flex** using command `make flex` (this currently only works on Linux and MACOSX). This command also creates several 
    header files (`location.hh`, `stack.hh`, `position.hh`) in directory `pkg/src/macro`.
  * `FlexLexer.h` is a local copy of the header file for Flex. It is copied from the system location (e.g. `/usr/include` on Linux)  by command `make flex` . Using a local header file
     for Flex makes it possible to compile the C++ code even if Flex is not available.
  * `DynareBison.cc` and `macro/MarcoBison.cc` are created with **Bison** using command `make bison` (this currently only works on Linux and MACOSX).

## Gitlab pipelines

For this package Gitlab pipelines are not used, because it takes quite long
to compile the C++ code.
